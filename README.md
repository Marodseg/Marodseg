## 👋 Sobre mí

Soy **Project Manager en [Hiberus](https://www.hiberus.com/)**, donde lidero proyectos digitales combinando visión de negocio y conocimiento técnico.

Vengo del mundo del **desarrollo Frontend**, lo que me permite entender el producto desde dentro: hablar el mismo idioma que el equipo técnico, anticipar riesgos y traducir las necesidades del cliente en entregas de valor reales.

- 🎯 **Enfoque:** entregar a tiempo, con calidad y con el cliente siempre informado.
- 🤝 **Estilo:** comunicación clara, equipos autónomos y mejora continua.
- 🌱 **Siempre aprendiendo:** nuevas metodologías, herramientas y tecnologías.

## 🧭 Lo que hago

| Área | Qué aporto |
| --- | --- |
| **Gestión de proyectos** | Planificación, seguimiento, gestión de riesgos, alcance y stakeholders |
| **Metodologías ágiles** | Scrum · Kanban · Ceremonias, roadmap y priorización de backlog |
| **Relación con cliente** | Definición de requisitos, reporting y expectativas alineadas |
| **Liderazgo de equipos** | Coordinación de perfiles multidisciplinares y desbloqueo del equipo |
| **Visión técnica** | Criterio Frontend para estimar, revisar y decidir con fundamento |
